An invented passport spread for a country that isn't there: the **Republic of
Velmara**, a windswept North Atlantic island of lighthouse-keepers, salt
farmers and fisherfolk, between Iceland and Norway. The open spread shows the
data page of holder **Asta Rennvik** (born 14 MAR 1988, Tarnvik; passport
VM4839201, issued 12 JAN 2024, expires 12 JAN 2034) with a drawn portrait and
a correct two-line MRZ, facing a visa page stamped with one plausible trip —
Keflavík (28 FEB 2024), Bergen (14 MAR 2024), home to Tarnvik (02 APR 2024),
Tórshavn (19 MAY 2024) — plus a small map of the island and the paperwork
detail that gives the place away: a light-keeper's endorsement ("MAY LAND ON
ALL LIGHT STATIONS") and an outer-isles ferry levy stamp (12 VKM, paid).

Bounty page: https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13 standard library only: it copies the shipped
`entry.png` (1024×1024, 180,700 bytes) to the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`) and verifies the copy is
byte-identical, exiting non-zero on mismatch.
